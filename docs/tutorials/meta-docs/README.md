# Meta Docs tutorials

[Meta Docs](../../plugins/meta-docs.md) supports separate-pass prose cleanup, multi-language and
mode-aware humanization, and execution-backed adversarial verification of documentation and plans.
Choose the workflow that matches your task.

| If you need to... | Follow this tutorial |
|---|---|
| Strip AI writing tells from a README, tutorial, or PR description without losing facts or commands | [De-slop and humanize documentation](deslop-and-humanize-docs.md) |
| Prove whether a specification, tutorial, or code change has broken commands, paths, or blind spots | [Stress-test docs and plans with `interrogate`](interrogate-docs-and-plans.md) |

All three skills (`unslop`, `humanize-skills`, and `interrogate`), the `docs-anti-slop-reviewer`
subagent, and `tutorial-engineer` prompts for maintaining these guides are documented in the
[Meta Docs plugin README](../../../plugins/meta/meta-docs/README.md).
